Guia do usuário

Tudo o que você precisa para usar o Nexo no dia a dia. Em dúvida, nexo help lista os comandos, e --help funciona em qualquer um.

O Nexo ainda não foi liberado para uso em projetos da empresa. Até lá, use só a demonstração.

Começar

1. Prepare a máquina

nexo setup --check     # mostra o que falta, sem instalar
nexo setup             # instala, sempre perguntando antes
nexo squad set sq-seu-squad
nexo doctor            # confere tudo

2. Experimente sem risco

nexo demo cli     # repositório de exemplo com agente simulado, e um roteiro para seguir
nexo demo site    # portal local, com um login para cada perfil

Tudo é fictício, não gasta tokens e não mexe nas suas configurações.

3. Entre no seu time

nexo join nome-do-time --repo endereço-do-repositório-do-time

Não precisa saber Git. A partir daqui, o Nexo sincroniza sozinho.

4. Prepare um repositório

Quem cuida do repositório faz isto uma vez:

nexo init
nexo team link nome-do-time --repo endereço-do-repositório-do-time
nexo context init           # poucas perguntas sobre o projeto e o repositório
nexo lineage agent install  # opcional: mantém a linhagem atualizada

O dia a dia

Digite só o seu papel para ver o que está com você, do mais antigo para o mais novo. nexo brief <id> explica o que fazer em qualquer demanda, e nexo board mostra tudo.

Contexto do projeto

Projeto é o conjunto maior, que pode ter vários repositórios, chamados de partes. Repositório é cada pasta de código. Quanto melhor o contexto, melhor a IA planeja.

QueroComando
Ver o contexto atualnexo context
Criar, com perguntas curtasnexo context init
Incluir uma regra ou decisãonexo context add "texto"
Explicar uma siglanexo context term "PMO" "escritório de projetos"
Pedir sugestões à IA, a partir de um documentonexo context enrich --from regras.md
Levar o projeto para os outros squadsnexo context propose id-do-projeto

O que a IA sugere só entra depois que você aceita. Texto com segredo ou dado pessoal é recusado.

Squad

nexo squad                  # mostra o seu e de onde vem
nexo squad set sq-seu-squad # vale em todos os repositórios
nexo squad list             # os que o Nexo conhece

Custo, métricas e flags por squad dependem disso. Ao entrar em um time com nexo join, o nome do time vira o seu squad, se você ainda não tiver informado um.

Portal

O portal mostra features, dashboard, insights, board e acessos. Cada pessoa vê o que o perfil dela permite. Na fase atual, o login é por convite; o SSO da empresa será conectado depois.

Quando algo dá errado

MensagemO que fazer
falta instalar antes de executarRode nexo setup. Nada foi gasto
identidade verificada exigidaRode nexo login github
ainda não está pronta: faltam as aprovaçõesRode nexo brief US-1-1 para ver quem precisa aprovar
guarda não comprovadaA ferramenta não pode receber esta classe de dados. Use outra, ou uma tarefa de classe permitida
A história escalounexo logs US-1-1 mostra o motivo, e nexo dev resume US-1-1 retoma
Comando desligado por flagnexo flags explain chave mostra quem desligou e por quê
Qualquer outra coisanexo doctor
