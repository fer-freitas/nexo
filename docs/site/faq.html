Perguntas frequentes

As dúvidas mais comuns, com o comando para resolver. Procure pelo Ctrl+F do navegador, ou use o índice ao lado.

Instalação

Como eu instalo o Nexo?

Com o pacote do time do Nexo, rode o instalador e depois o setup. Ele não exige Python na máquina nem administrador.

nexo install
nexo setup

Se você vai mexer no próprio Nexo, instale pelo código-fonte: python -m venv .venv e pip install -e ".[dev]", dentro da pasta do repositório.

O que o nexo setup instala?

Ele confere e instala o que falta: Git, o gitleaks, as ferramentas exigidas pela stack do repositório e as de segurança. Pergunta antes de cada instalação, e ao final pede o seu squad.

nexo setup --check    # só mostra o que falta
nexo setup            # instala, perguntando antes
nexo setup --yes      # instala sem perguntar
Como instalo uma ferramenta de IA pelo setup?

Indique qual delas com --agent. Se não houver instalador disponível na máquina, o setup avisa, e você instala pelo procedimento da ferramenta.

nexo setup --agent claude
nexo login claude
Como sei se está tudo certo?

O nexo doctor mostra o que está pronto e o que falta nesta máquina: ferramentas, cérebro, squad, identidade e o que cada item pede para você fazer.

nexo doctor
Como atualizo?

O Nexo baixa a versão nova e confere a assinatura dela antes de instalar.

nexo update
Como desinstalo?

O comando remove o Nexo. Com --purge, também apaga os dados dele nesta máquina.

nexo uninstall
nexo uninstall --purge
Posso experimentar sem risco?

Sim. Os dois comandos abaixo usam dados fictícios, não gastam tokens e não mexem nas suas configurações.

nexo demo cli
nexo demo site

Primeiros passos

Como entro no meu time?

Peça ao tech lead o endereço do repositório do time e rode o comando abaixo. Não precisa saber Git: depois disso, o Nexo sincroniza sozinho.

nexo join nome-do-time --repo endereço-do-repositório
Como informo o meu squad?

Custo, métricas e flags por squad dependem disso. O valor vale para você em todos os repositórios.

nexo squad set sq-seu-squad
nexo squad          # mostra o atual e de onde vem
nexo squad list     # os que o Nexo conhece

Com --project, vira o padrão do repositório para quem ainda não informou.

Como informo a sigla do projeto?

Todo projeto da empresa tem uma sigla. Ela aparece no contexto que a IA recebe e no portal, onde também serve de filtro: todos os repositórios do projeto entram juntos.

nexo context project new custodia --sigla CDT
nexo context project sigla custodia CDT   # para um projeto que já existe
nexo context project list                 # sigla, id e nome

A sigla tem de 2 a 8 letras ou números, e cada uma pertence a um projeto só.

Como filtro o portal por squad?

Quem enxerga mais de um squad vê a linha Squads no alto das páginas de dados. Marque um ou vários e clique em Filtrar. A escolha continua valendo ao trocar de página, e Ver todos desfaz. O filtro só reduz o que você já pode ver: pedir um squad fora do seu acesso é recusado.

Como preparo um repositório?

Quem cuida do repositório faz isto uma vez.

nexo init
nexo team link nome-do-time --repo endereço-do-repositório
nexo context init
Como faço login?

As credenciais ficam no cofre do sistema, nunca em arquivo. As ferramentas de IA abrem o login delas no navegador.

nexo login github
nexo login claude
Como descubro o que está comigo?

Digite só o seu papel. A lista vem do mais antigo para o mais novo, e nexo brief explica o que fazer em cada demanda.

nexo pm
nexo brief F-1
nexo board --mine
Qual é a diferença entre o console e os comandos?

Digitar só nexo abre o console: ele mostra os próximos passos, e você escolhe pelo número ou escreve do seu jeito. Os comandos fazem a mesma coisa, de forma direta.

Cérebro

O que é o cérebro?

É o repositório de conhecimento da empresa: skills, padrões, lições, política e o contexto dos projetos. A IA consulta a versão assinada, e toda mudança entra por PR.

Como conecto no cérebro?

Informe o endereço do repositório e a chave pública que o time do cérebro divulga, faça login no GitHub e baixe a versão assinada.

nexo config set brain.repo endereço-do-nexo-brain
nexo config set brain.trusted_keys "[chave-publica]"
nexo login github
nexo brain pull
nexo brain status

Se o Nexo veio pré-configurado pela empresa, só o nexo brain pull basta.

Como mantenho o cérebro atualizado?

Ele atualiza sozinho em segundo plano. Para forçar, rode o comando abaixo.

nexo brain pull
O pull recusou o cérebro. O que faço?

A assinatura não bateu com a chave confiável, ou a chave foi revogada. Confira a chave com o time do cérebro. Até resolver, o Nexo segue com a última versão verificada.

nexo brain status
Como procuro algo no cérebro?

A busca cobre skills, padrões e lições. Para ver o que se liga a uma nota, use neighbors.

nexo brain search "termo"
nexo brain neighbors id-da-nota
nexo brain path id-a id-b
Como proponho uma lição ou um padrão?

Escreva a nota em um arquivo e proponha. Com um clone de trabalho do cérebro, o Nexo prepara o branch do PR. Sem clone, abre uma proposta para o time do cérebro.

nexo brain propose nota.md --clone pasta-do-clone --target lessons/nota.md

Texto com segredo ou dado pessoal é recusado.

Como abro o cérebro no Obsidian?

Clone o repositório nexo-brain e abra a pasta como um vault. Os links e o grafo funcionam, e os arquivos do Obsidian ficam fora da assinatura.

Como confiro um PR do cérebro?

O revisor roda o mesmo lint que a assinatura exige, sem mexer na pasta de trabalho.

nexo brain review 123 --path pasta-do-clone

Contexto do projeto

Qual é a diferença entre projeto e repositório?

Projeto é o conjunto maior, que pode ter vários repositórios, chamados de partes. Repositório é cada pasta de código.

Como conto à IA sobre o meu projeto?

O comando faz poucas perguntas e grava o contexto do repositório em .nexo/contexto.md.

nexo context init
nexo context
Como enriqueço o contexto?

Inclua direto uma regra ou um termo, ou peça sugestões à IA a partir de um documento. O que ela sugere só entra se você aceitar.

nexo context add "Não mexer no legado de boletos"
nexo context term "PMO" "escritório de projetos"
nexo context enrich --from regras.md
Como levo o projeto para outros squads?

O rascunho fica na sua máquina até ser proposto ao cérebro.

nexo context propose id-do-projeto

Demandas e fluxo

Como registro uma ideia?

Não usa IA e já gera o ID. Depois, a PM decide se segue e divide em features.

nexo pm idea "Simulador de parcelas"
nexo pm decide IDEA-1 build --reason "motivo"
nexo pm split IDEA-1 --feature "Simulador"
Por que a minha história não roda?

Faltam aprovações: QA e dev precisam aprovar a parte de cada um. O nexo brief mostra quem falta.

nexo brief US-1-1
nexo qa approve US-1-1
nexo dev approve US-1-1
Como troco o responsável?

O tech lead indica por feature ou por história, e a troca fica registrada com o motivo.

nexo tl assign F-1 --dev pessoa --qa pessoa
nexo tl reassign US-1-1 --dev pessoa --reason "motivo"
Encontrei um problema no meio. E agora?

Abra o problema, sem precisar saber a quem recorrer. O Nexo calcula o dono da parte afetada. Depois da decisão, a IA refaz só o que foi afetado.

nexo dev problem US-1-1
nexo dev resume US-1-1
Como registro um bug?

O bug nasce ligado à história e volta para o dev.

nexo qa bug US-1-1 "descrição"
nexo qa verify BUG-1
Como acompanho reuniões de refinamento?

Abra a reunião, registre notas com prefixos, e cada dono revisa o que for dele ao fechar.

nexo meeting start F-1 --type funcional --with pessoa
nexo meeting note "critério: parcela mínima de R$ 10"
nexo meeting close

IA e execução

Quais ferramentas de IA o Nexo usa?

Claude Code, Devin e Copilot. O Nexo escolhe a rota pelo custo e pela qualidade para cada tipo de tarefa. Para forçar uma, use --tool.

nexo dev run US-1-1 --tool claude
O que acontece quando a cota acaba?

A tarefa continua em outra ferramenta permitida, com o contexto. Se não houver nenhuma, ela fica bloqueada até a cota voltar, e nexo dev resume retoma.

Por que apareceu "guarda não comprovada"?

A ferramenta ainda não teve o bloqueio provado, então não recebe dados confidential nem restricted. Use outra ferramenta, ou uma tarefa de classe permitida.

nexo doctor
Como digo a classe de dados do repositório?

Ela define o que pode ir para cada fornecedor.

nexo config set data_class internal --project
Posso testar algo sem criar demanda?

Sim. O teste livre não abre PR nem aprova nada, e dá para promovê-lo a demanda depois.

nexo try "pedido"
nexo try list
nexo try promote TRY-1
Como pergunto sobre o código?

A resposta vem com as fontes.

nexo ask "Onde calculamos a parcela?"
Como uso os comandos dentro do Claude ou do Copilot?

O comando cria atalhos como /nexo-pm-refine no repositório, que chamam o Nexo com as mesmas regras.

nexo pack expose
nexo pack expose --for copilot
O que é a guarda?

Ela leva a política do Nexo para sessões do Claude Code abertas fora dele. Fica instalada na configuração do Claude da sua máquina, e dá para conferir ou remover.

nexo guard status
nexo guard uninstall

Portão e qualidade

Como sei por que o portão pediu uma decisão?

O comando mostra o que reprovou, o que pede uma pessoa e o que fazer agora.

nexo tl gate US-1-1
Como aprovo ou reprovo?

Reprovar exige motivo e devolve a história com um bug ligado.

nexo approve US-1-1
nexo reject US-1-1 --reason "motivo"
Por que a IA não pode mudar os testes?

Os testes de aceite são escritos antes e ficam travados. Se a implementação os alterar, o portão reprova.

Quando o portão pede uma pessoa?

Em área sensível, como pagamentos e autenticação, sem revisão por outro fornecedor, ou com confiança abaixo do limite.

Como rodo a qualidade na minha máquina?

São as mesmas etapas que a história passa, conforme a stack do repositório.

nexo qa run

Portal, custo e dados de uso

Como entro no portal?

Pelo endereço que o time do Nexo divulga, com o token que quem administra o portal cria para você. Cada pessoa vê o que o perfil dela permite.

Como ligo a minha máquina ao portal?

Informe o endereço, ligue o envio e aprove o pareamento no navegador, sem colar token.

nexo config set telemetry.url endereço-do-central
nexo config set telemetry.enabled true
nexo central pair
nexo central status
O que sai da minha máquina?

Ferramenta, modelo, tokens, custo e etapas. Prompts, respostas, código e caminhos não saem. O comando abaixo mostra exatamente o que foi e o que vai ser enviado.

nexo telemetry show --pending
E se o portal estiver fora do ar?

O trabalho segue normalmente. Os eventos esperam na fila e são enviados depois, sem duplicar.

Quanto estou gastando?

O custo sai em reais, por pessoa, história e projeto. Quem gere o orçamento pode definir um teto.

nexo cost
nexo cost usage
nexo cost budget set
Como desligo uma funcionalidade?

Pelo portal, em Feature flags, ou pela CLI. Sempre com motivo, e os controles de segurança não têm flag.

nexo flags list
nexo flags explain chave
nexo flags set chave off --reason "motivo"
Um comando diz que está desligado. Por quê?

Alguma flag o desligou. O explain mostra quem desligou e de onde vem o valor.

nexo flags explain chave

Linhagem e integrações

Como ligo a linhagem?

O agente roda a cada 30 minutos, com a máquina ligada, sem tocar na sua pasta de trabalho.

nexo lineage agent install
nexo lineage agent status
Como vejo quem consome o meu componente?

A resposta traz o estado de cada ligação. coverage mostra o que falta para o mapa ficar completo.

nexo lineage show nome-do-componente
nexo lineage impact kafka:nome-do-topico
nexo lineage coverage
Como conecto um MCP?

Busque, ligue no projeto, prepare a aprovação no cérebro, faça login e prove com uma chamada real. Sem aprovação, ele não entra nas execuções.

nexo mcp search postgres
nexo mcp add id-do-mcp
nexo mcp approve id-do-mcp --brain pasta-do-clone
nexo login mcp_id-do-mcp
nexo mcp test id-do-mcp
Como envio demandas para o GitHub Issues?

Configure a ferramenta de gestão e sincronize. Reenviar não duplica.

nexo tracker sync
nexo board --sync
Como recebo avisos por e-mail?

Informe o servidor de e-mail e os destinatários. Se ele exigir usuário, guarde a senha com nexo login smtp. O e-mail cobre história, portão, dúvida do agente, orçamento, planejamento e mudança.

nexo config set notify.channels.email true
nexo config set notify.email.host servidor-de-email
nexo config set notify.email.to "[time@empresa.com]"
nexo notify test
Como testo os avisos?

A mensagem de teste mostra o resultado de cada canal ligado.

nexo notify test

Quando algo dá errado

Por onde começo?

O nexo doctor aponta quase tudo. Para o histórico de uma demanda, use nexo logs.

nexo doctor
nexo logs US-1-1
Apareceu "falta instalar antes de executar".

Falta uma ferramenta sem a qual o portão não valida a entrega. Nada foi gasto.

nexo setup
Apareceu "identidade verificada exigida".

O Nexo precisa saber quem você é para registrar autoria e aprovações.

nexo login github
A história escalou.

O motivo está na linha do tempo. Depois de resolver, retome de onde parou.

nexo logs US-1-1
nexo dev resume US-1-1
Como vejo a ajuda de um comando?

--help funciona em qualquer comando, e nexo help lista todos por papel.

nexo help
nexo pm refine --help
