Nexo

Uma ferramenta de linha de comando para PM, QA, tech lead e dev que conduz o trabalho do pedido até o PR, usando as IAs já aprovadas pela empresa. Quem decide o que passa são portões determinísticos, não a IA.

Estado atual: em construção, antes da primeira liberação. O código está feito e validado em macOS, mas nada foi provado no Windows da empresa nem na AWS. O detalhe está em Features.

Como funciona

O caminho de uma demanda, quem age em cada etapa e o que acontece quando surge um problema no meio.

Arquitetura

As peças, onde cada uma roda, por onde passam os dados e as decisões técnicas.

Features

O que existe hoje e o estado de cada item: provado de verdade, só com simulador ou pendente.

Para executivos

O problema, a proposta, os controles, como medir o retorno e a decisão que precisamos.

Guia do usuário

Instalar, experimentar sem risco e usar no dia a dia, por papel.

Experimente em dois minutos

Nenhum dos dois comandos gasta tokens nem toca nas suas configurações. Tudo usa dados fictícios.

nexo setup       # confere e instala o que falta
nexo demo cli    # repositório de exemplo, com agente simulado
nexo demo site   # portal em 127.0.0.1, com um login por perfil
